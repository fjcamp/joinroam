# JoinRoam — Diagnóstico y habilitación de espacios turísticos
**Estado:** DISEÑADO / PROPUESTA OPERATIVA  
**Fecha:** 2026-10-20  
**Ámbito inicial:** Choshuenco, comuna de Panguipulli, Región de Los Ríos. Confirmar ubicación y alcance exactos de cada predio antes de iniciar.

## Objetivo
Convertir una consulta de propietario en un proceso ordenado de evaluación, diagnóstico, cotización y, si el cliente lo aprueba, gestión de implementación de un espacio para estadías de campers, motorhomes, casas rodantes u otros visitantes, sujeto a factibilidad técnica, territorial, sanitaria, municipal y normativa.

JoinHook/JoinRoam coordina, levanta información, compara alternativas y gestiona proveedores. No debe presentarse como autoridad, certificador ni sustituto de arquitectos, ingenieros, instaladores autorizados, profesionales sanitarios, abogados, contadores o funcionarios municipales cuando corresponda.

## Principios de control
1. **No prometer habilitación al 100% antes de validar factibilidad y permisos.**
2. Separar honorarios JoinHook, gastos reembolsables, servicios externos, obras/materiales, derechos y permisos.
3. Cada estimación debe indicar fecha, proveedor, alcance, impuestos, vigencia y exclusiones.
4. La visita de terreno, estudios especializados y trámites posteriores se cotizan de forma explícita; no se regalan dentro de una evaluación inicial sin límite.
5. No contratar obras ni proveedores sin autorización escrita del propietario.
6. Registrar evidencias, responsables, supuestos, riesgos y decisiones en Gestión Admin cuando el módulo esté implementado y probado.
7. Ningún dato sin respaldo se presenta como hecho: **NO EVIDENCE = NO CLAIM**.

## Estado actual
Este paquete define un modelo de trabajo. No acredita visita a terreno, estudio de mercado realizado, cotizaciones recibidas, permisos concedidos ni software implementado.
